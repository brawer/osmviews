# Defensive publication

**Method for Memory-Bounded Construction of a Globally Complete,
High-Zoom-Level Cloud-Optimized GeoTIFF from Tile-Access Logs**

A prior-art disclosure of the techniques used by `cmd/osmviews-builder` to
build the OSMViews Cloud-Optimized GeoTIFF, and by the `osmviews-rs` /
`osmviews-py` client libraries to read it. Published on Technical Disclosure
Commons: <https://www.tdcommons.org/dpubs_series/11589>.

- **`defensive-publication.pdf`** — the published artifact (A4, two columns,
  tagged PDF/UA-2 + PDF/A-4f). This is the file that goes to tdcommons.org.
- **`defensive-publication.tex`** — the single source. Everything is edited
  here.
- **`Makefile`** — `make` builds the PDF, `make check` validates it.

The document text is licensed **CC BY 4.0**; the reference implementations stay
MIT.
